# v4.0.0 - Sprint 4: Gestión de membresías
- Sprint planificado: 27 octubre - 6 noviembre 2026
- Entregado: E4-HU1 Registrar una membresía, E4-HU2 Consultar la membresía de un usuario, E4-HU3 Renovar una membresía, E4-HU4 Consultar el vencimiento de las membresías
- Base de datos: tablas `membresias`, `membresia_periodos` (historial) y `alertas_membresia`; el estado (Activa, Próxima a vencer, Vencida) se calcula con la fecha de hoy
- API: `/api/membresias` (administrador) y `/api/mi-membresia` (usuario)
- Reglas: una membresía por usuario; tipos Mensual, Trimestral, Semestral y Anual; próxima a vencer = 5 días o menos; se puede renovar cuando vence en 30 días o menos o ya venció; una alerta por vencimiento
- Pantallas: Membresías (administrador) y Mi membresía (usuario)
